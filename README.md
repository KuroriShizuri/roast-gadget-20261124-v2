## The entry

> Opening two Chrome tabs turns my laptop into a leaf blower that also does spreadsheets.

87 characters, exactly one line. The roast targets the laptop — the
gadget every laptop user hears every single day.

## How it works

`main.py` (Python standard library only, no network) validates the
competition constraint BEFORE writing — exactly one line, at most 200
characters, non-empty — then writes the fixed one-liner to
`/output/entry.txt` and re-reads the file to confirm the exact string
written matches, and exits with status 1 if any check fails.

Run it:

```sh
python3 main.py
```
